# EchoVerse — Data Structures in Java

Academic console application demonstrating AVL trees, Dijkstra's shortest paths, general tree traversals, and min-heaps. Organized into separate Java phases with a menu-driven entry point.

## Technologies
Java, data structures, graph algorithms

## Run
From this repository directory:

```sh
javac -d build src/Main.java src/Phase1/*.java src/Phase2/*.java src/Phase3/*.java src/Phase4/*.java
java -cp build Main
```

The repository contains source files only; IDE project settings and compiled classes were removed for portability.

Academic project; the author's exact contributions and any team credits should be documented before publication.
